# Release notes — v1.0.0 (DRAFT, not tagged)

> **Draft.** These notes cover every customer-visible change merged since the QA-1 work
> (PR #2, 2026-10-12) up to the role navigation fixes (BUG-0010, BUG-0011, 2026-10-17). Per
> Charter §18 they use the words each audience would recognise, and security fixes describe
> the improvement, not the mechanics. Publish them with the first tagged release. No tag has
> been created.

## For electricians
- **Scanning on an iPhone.** The *Scan* page no longer switches the camera on when the browser
  cannot read QR codes (iPhone Safari): it asks you to type the code printed under the QR code,
  which finds the location and its tickets as before.
- **The menu links work again.** *Tickets*, *My Work* and *Scan* had started opening a
  'not found' page.
- **Picking up tickets works again.** The *Pick Up* button had stopped working in the
  electrician app; it now moves the ticket to *In progress* as expected.
- **You can see the photos.** Complaint photos and the proof photos you attach now show in
  your ticket list.
- **Reset a forgotten PIN from the email link.** The *Reset PIN* link in the email now opens a
  page where you choose a new 6-digit PIN, then sign in with it.
- **An Employee ID is required.** You always sign in with your Employee ID and PIN; your
  admin now has to enter an Employee ID when adding you.
- **You hear how your fix went.** When a supervisor verifies your work, or sends it back, you
  get a notification. A fix that was sent back shows the supervisor's reason, and tapping the
  notification opens your tickets.
- **A finished ticket stays finished.** A ticket that is waiting for verification, or already
  verified, can no longer be resolved again by mistake.
- **When a guest says it is not fixed,** you are told, with their words, and the complaint is
  back in your Pool so you can pick it up again. Before, it showed as "Done" with no way to
  take it back.

## For supervisors
- **Asset updates confirm properly.** After logging an inspection, maintenance or repair, or
  reporting a failure, you see the confirmation and *Back to Asset*; it used to be a blank page.
- **A new duty roster suggests the right electricians.** The electricians covering the
  location are pre-selected, also when they cover it from the building.
- **The menu links work again.** *Scan*, *Electrical*, *Assets*, *Tickets* and *Attendance*
  had started opening a 'not found' page.
- **One notification per public complaint.** If you are responsible for the location, you no
  longer receive the same complaint twice.
- **Complaints and tickets go to the nearest responsible supervisor.** When several
  supervisors cover a location, a new complaint or ticket is consistently assigned to the
  one closest to it.
- **A second guest review after a rejection.** If a guest rejected a fix, verifying the next
  fix now creates a new review link for them; before, the guest could not review it.

## For admins
- **Reopening a resolved complaint keeps it open.** Moving a resolved public complaint back
  to *In progress* now cancels the guest's pending review link. Before, that link, or the
  automatic acceptance when it expired, could close the ticket while it was being worked on.
- **Every admin page has the same menu.**
  - The Assets, Failures and Electrical pages had a broken menu bar that also made them
    scroll sideways on a phone.
  - Predictive Maintenance had no menu at all.
  - Alerts was dark, and its menu could not be opened on a phone.
  - On Assets, Failures and Electrical, the *Logout* button now works.
- **Clearing a field now saves.** When editing an asset (make, model, serial number, dates,
  maintenance cycle, cost), a location (notes) or an alert rule (description), a field you
  empty stays empty; before, the old value came back. A location can also be moved back to
  *None (Top Level)*.
- **Analytics shows numbers, not "undefined".** *Inspection Records*, *Flagged Records* and the
  Location Breakdown now show 0, or "—" where there is no schedule.
- **Accessibility:** the filters on Analytics, Attendance, Categories, Assets, Failures and
  Electrical, and the supervisor's Attendance page, are announced by screen readers. The "All
  modules" link on the module page is readable.
- **Password reset links from email work.** They now open a page where you choose a new
  password.
- **Electrician PINs are 6 digits.** The *Set PIN* window now asks for exactly 6 digits,
  matching what the sign-in accepts.
- **Clearer messages when a supervisor can't be deleted.** Permanently deleting a supervisor
  who still has history (tickets they created, attendance they marked, duty rosters, asset
  records or inspections) now explains which records keep them, instead of showing a server
  error.
- **Restored actions:** acknowledging alerts (one or all), generating AI insights and
  duplicating inspection templates work again.
- **Accessibility:** screen readers now announce the mobile menu button.
- **Alert escalations reach the right people.** An alert rule that escalates to the
  supervisors or electricians of the location, or raises a ticket there, now does so. Before,
  only the admins' escalation notice went out.

## For guests (public complaint page)
- **Fairer limits on repeated submissions.** Rapid repeated complaints are now limited per
  network, as intended. People sharing one Wi-Fi network (for example a campus) share that
  allowance; normal use is unaffected.

## For super-admins
- **New Quality page** (linked from the super-admin dashboard):
  - the latest automated test run, a 30-run trend and run history with detail per file and
    per failure, with a clear warning whenever some tests did not run;
  - live CI status;
  - **Run production checks:** a read-only health check of the database, offsite backups,
    email, configuration and build;
  - an **End-to-end** tab with the latest browser test run (journeys, accessibility and
    visual checks, with links to the report) and a **Run full test suite now** button.
- **More reliable under load.** A fault where loading many photos could make the whole
  platform briefly unavailable has been fixed.
- **New organizations without an email.** Creating an organization with the Email field left
  empty used to fail with "Validation failed"; it now works.

## Behind the scenes (no change in how you use the product)
- Security updates to the platform's components, and a new automatic check that blocks
  releases with known-vulnerable components.
- A newer, long-term-supported runtime (Node.js 24 and Fastify 5).
- Sensitive links are kept out of server logs, and backups are verified offsite.
